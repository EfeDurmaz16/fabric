# EfeDurmaz16/homebrew-tap

Homebrew formulae for [Fabric](https://github.com/EfeDurmaz16/fabric).

```sh
brew install EfeDurmaz16/tap/fabric
```

The formula installs the prebuilt, unsigned binary from the newest GitHub
Release. Its source, the job that updates it and the checks that job runs
are in `packaging/homebrew-tap` of the Fabric repository; do not edit
`Formula/` by hand.
